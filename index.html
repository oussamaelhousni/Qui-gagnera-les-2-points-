    À vous les commandes.

    Choisissez un élève dans la classe, puis démarrez. Cliquez sur sa réponse, validez et laissez le suspense jouer. Vous passez vous-même à la question suivante.

    • 50:50 : sélectionnez les deux mauvaises propositions à retirer, puis confirmez. Vous pouvez annuler avant de confirmer.
    • Le professeur / Un ami : donnez la parole à la personne choisie, puis cliquez sur « Reprendre la question ». Chaque joker est utilisable une seule fois par partie.
    • Une erreur : la partie se termine. Les +2 points sont attribués uniquement pour 10 réponses correctes.

    Vos questions, votre partie.

    Chargez un fichier JSON contenant exactement 10 questions de difficulté croissante. Gardez cet ordre : chaque question comporte quatre réponses et une lettre correcte de A à D.

    {
  "title": "Mon quiz",
  "questions": [
    {
      "question": "Combien font 2 + 2 ?",
      "options": ["3", "4", "5", "6"],
      "correctAnswer": "B",
      "explanation": "2 + 2 = 4."
    }
  ]
}

    L’exemple montre une seule question ; votre fichier doit en contenir 10. Un tableau de questions sans objet parent est aussi accepté. Les sons sont créés sur place ; aucune connexion n’est nécessaire.

    Recommencer la partie ?

    La progression et les jokers seront remis à zéro.
